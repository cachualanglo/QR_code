# File status legend

- 🟩 **GREEN — reusable template file:** maintained once and reused across projects. These files contain rules, gates, conventions, and reusable prompts.
- 🟨 **YELLOW — generated project file:** generated or updated from the current project's requirements, approved contracts, approved Stitch design, source code, and runtime evidence.
- ⛔ A generated file is never considered approved merely because it exists. It must pass its corresponding gate.
